# Staying sharp

Daily practice for Prof. Roger Hunt's courses at Hult. Use these prompts outside class so the work stays in your hands.

Every day, do three things:

1. **One CCAT practice test.** Open [ccat-practice-prompt.md](ccat-practice-prompt.md). Copy the prompt into Claude, or any AI chat that can make artifacts or interactive HTML. Take the test yourself. Check answers only at the end.
2. **One logic and Python exercise set.** Open [logic-python-prompt.md](logic-python-prompt.md). Copy the prompt into Claude, or any AI chat that can make artifacts or interactive HTML. Do the steps yourself. Check answers only at the end.
3. **One LeetCode planning write-up.** Open [leetcode-planning-prompt.md](leetcode-planning-prompt.md). Copy the template into a doc, or write it by hand. Plan the problem before you write code. Use the critique prompt only after you have a real draft.

AI is for building the practice, not doing it. In class there are no devices, so you need to be able to do this by hand.

A short session every day is enough. Finish the three, then stop.
