# CCAT practice

Copy the prompt below into Claude, or any AI chat that can make artifacts or interactive HTML. Take the test yourself, and check answers only at the end.

```text
Create a complete interactive CCAT practice test as a Claude Artifact (HTML + JavaScript + CSS).

Requirements:

- Exactly 50 original multiple-choice questions that realistically mix:
  • Verbal (analogies, antonyms, sentence completion, word relationships)
  • Math & Logic (percentages, ratios, averages, number series, word problems — no calculator needed)
  • Spatial / abstract reasoning (shape series, matrices, odd-one-out, rotations)

- 5 answer choices (A–E) for every question, with exactly one correct answer.
- One question displayed at a time.
- Large, clear clickable buttons for answers.
- Live 15-minute countdown timer that starts the moment the student clicks “Start Test”.
- Progress indicator (e.g. “Question 12 of 50”).
- Ability to go to the next question after selecting an answer (or skip).
- Optional “Previous” button for practice purposes.
- At the end of 15 minutes or when the student finishes all questions:
  - Show final score out of 50
  - Show how many questions were answered
  - List every question with the student’s answer, the correct answer, and a clear step-by-step explanation
- Clean, modern, distraction-free design that feels like a real online test.
- Mobile-friendly.
- Do not show any answers or explanations until the test is finished or time runs out.
- Make the questions original and of realistic CCAT difficulty.

Start the Artifact with a “Start Test” button that begins the timer and shows Question 1.
```
