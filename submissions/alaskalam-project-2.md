## Summary

**Mindful Communications** — a mindful communications app where you're encouraged to pause before posting, built with Python & Streamlit.

- Repository: https://github.com/alaskalam/mindful_communicationsapp

- **Pause before posting a new thread** — a brief reminder to yourself to ask if you really want to post this AND if it makes sense to others reading, logistically
