# Project 1 Submission — @frankgomezdev

Cohort PM — a project management tool for the summer26 cohort, built so the standard it's judged by is how motivational it is.

Repo: https://github.com/frankgomezdev/pm-frankgomezdev
Production URL: (https://pm-frankgomezdev.vercel.app/)

Built with Next.js 15 (App Router) + React 19, Firebase Auth + Firestore, and Tailwind v4 + Catalyst. The motivation layer is built on the Progress Principle, Self-Determination Theory, and goal-setting research rather than points and badges: a progress-first home, a blocker/stall radar, goal-quality nudges, autonomy controls, and a deliberately collaborative (non-competitive) design. Full write-up in the PR description.
