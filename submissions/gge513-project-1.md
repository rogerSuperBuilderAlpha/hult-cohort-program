# Project 1 Submission — @gge513

Whose Ball, a project management platform built on one bet: make meaningful progress easier to see than unfinished work, and make the next useful action easier to choose than avoidance.

Repo: https://github.com/gge513/whose-ball
Production URL: https://whose-ball.vercel.app

Next.js 16 (App Router) + Auth.js v5 + Neon Postgres (Drizzle), on Vercel. The motivation layer ships as mechanics, not points: one named next action per project (the ball), pass/catch/drop handoffs with a rally count, assists scored to unblockers, a dead-ball whistle whose remedy matches the cause, and a momentum page with no ranking anywhere. Full write-up in the PR description.
