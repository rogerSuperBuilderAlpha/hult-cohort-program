## Project Description
Grow Sprout gives every builder in the cohort a personal command center for their projects, tasks, blockers, and daily check-ins. Everyone's progress rolls up into one shared board, so the whole cohort can see who's on track, who's blocked, and who needs a hand.

## Main Features
- Two surfaces
- Individual project boards
- Cohort-wide progress dashboard
- Momentum score
- AI companion (sprout)
- Focus session
- Feedback flags
