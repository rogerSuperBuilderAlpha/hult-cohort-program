# Partner README — Trailmark

**Audience:** Hiring partners evaluating the Hult Cohort Developer Program Summer Pilot 2026.

**One sentence:** Don’t trust our word — inspect their GitHub. Trailmark is the public surface that makes that trail readable.

## What you get

- Directory of enrolled participants with campus, skills, and bios
- Links to repositories and live deploys where available
- Read-only cohort project status mirrored from the PM platform (FlexiFlow)
- Intro requests routed to the placement lead
- RSVP for the **19 August 2026** hiring partner showcase (Hult Boston + virtual)

## How to hire

1. Browse `/people` and open profiles.
2. Submit `/partners/intro` for the students you want to meet.
3. Placement confirms student opt-in (24h SLA) and schedules the intro.
4. Run your interviews. Fee invoices on employment start.

## Commercial terms (summary)

| Term | Value |
|------|-------|
| Fee | 25% of first-year base salary |
| Trigger | Candidate starts employment |
| Clawback | 100% within 90 days if terminated for cause / quits |
| Exclusivity | None |
| Kickback | 10% of collected fee to the hired graduate |

Full partner policy lives in the program repo under `partnerships/hiring-partners.md`.
