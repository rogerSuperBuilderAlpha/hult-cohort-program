## Architecture summary

- Frontend: Next.js 15 App Router
- Language: TypeScript25
- Styling: Tailwind CSS
- State persistence: Browser localStorage
- Hosting: Vercel

Core modules include Executive Summary, Initiative Summary, progress tracking, navigation, and theme management.

## Motivation / engagement design notes

- Real-time progress visibility
- Cohort completion tracking
- Colour-coded status indicators
- Trophy rewards for fully completed rows
- Dark mode support
- Quick initiative navigation
- Gamified completion percentages

## Known limitations

- No backend database
- No authentication
- LocalStorage-only persistence
- No cross-device synchronization
- Placeholder initiative detail pages
- Placeholder deadline values
