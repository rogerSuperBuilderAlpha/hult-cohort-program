# Lighthouse — partner guide

**Audience:** Hiring partners evaluating the Hult Cohort Program Summer Pilot 2026.

## What this site is

Lighthouse is the public showcase for the cohort. Every enrolled participant has a profile page. Public profiles link to GitHub and to Phase 1 build/deploy artifacts. A read-only snapshot of cohort project status from the PM platform appears on the homepage so you can see what is shipping — not a disconnected brochure.

**Core pitch:** Don’t trust our word — inspect their GitHub.

## How to evaluate a candidate in ~10 minutes

1. Open **Developers** and filter by campus or skill.
2. Open a profile → GitHub + deploy URLs + project showcase.
3. Skim homepage **Cohort project status** / Live Summary for live program context.
4. Use **Request intro** on the Partners page (profiles deep-link with `?developer=`).

## Commercial terms (summary)

- Referral fee ≈ **25% of first-year base salary** on successful hire
- **90-day clawback**
- **10% kickback** of the fee to the candidate (alignment)

Full partner pipeline detail lives with the program’s placement lead.
